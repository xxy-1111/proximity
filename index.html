Sequencing-Based Proximity Proteomics：从抗体-抗原识别到高通量蛋白定量

面向科研新手的技术路线、核心机制与研究版图

一句话理解：用一对抗体把同一个蛋白"夹"住，让两条分别挂在抗体上的 DNA 标签彼此靠近；这种"靠近"会触发一次核酸反应，把蛋白识别事件转成一段可测序的 DNA 条形码——最后测序仪读到的不是蛋白本身，而是"哪个蛋白被夹住了、被夹了多少次"。

核心机制流程图（Protein → 夹心结合 → oligo 邻近 → 核酸反应 → DNA 产物 → NGS → 身份 + 丰度）

关键认知：测序仪读的是"由蛋白识别事件转换出来的核酸信号"，不是直接测蛋白。蛋白本身在反应后被丢弃，留在体系里的只是代表它身份与含量的 DNA 条形码。

2. 5 分钟入门 Glossary▾

11 个核心概念，点开头看一句话解释 + 小图 + 在体系中的作用。

Sandwich assay（夹心法免疫检测）▾
一句话：一个蛋白被"上、下"两个识别分子同时夹住。
作用：双重识别把单分子信号变成"两个事件同时发生"，天然过滤掉只被单个抗体误结合的假阳性。本方向的双抗体 PEA/PLA 就是一种溶液相夹心。
Affinity antibody（亲和抗体）▾
一句话：能高特异性、高亲和力结合特定蛋白表位的 Y 形免疫球蛋白。
作用：整个技术的"识别端"。选哪一对抗体、对同一蛋白上哪两个不同表位，决定了信号的特异性与背景。
Oligonucleotide / Oligo tag（寡核苷酸标签）▾
一句话：一段人工合成的短单/双链 DNA，共价挂在抗体上。
作用：它既是"分子标签"（每个蛋白配一条独特序列），又是"反应元件"（两条 oligo 靠近时才能杂交并被聚合酶/连接酶利用）。
Proximity assay（邻近检测）▾
一句话：只有两个识别分子真正"靠近"时才产生信号。
作用：把"结合"这个低特异性事件升级成"两个识别事件同时发生在同一分子上"，是高特异性与均相（免洗涤）检测的核心。
Proximity ligation（PLA，邻近连接）▾
一句话：两条邻近 oligo 被 DNA 连接酶拼成一条完整可扩增链。
作用：PLA 的标志性反应。2002 Fredriksson 首次证明；缺点是连接酶在血浆中易被干扰，后被 PEA 用聚合酶路线改进。
Proximity extension（PEA，邻近延伸）▾
一句话：两条邻近 oligo 杂交后，由 DNA 聚合酶把一条链延伸过另一条探针臂。
作用：PEA 的标志性反应，解决了连接酶在血浆中受干扰的问题；Olink 商用平台全部基于 PEA。
Template-dependent extension（模板依赖延伸）▾
一句话：聚合酶以另一条邻近 oligo 为模板，按碱基互补合成新链。
作用：只有当两条 oligo 真正邻近并互补配对时，聚合酶才有模板可读——这是"邻近"被翻译成"序列"的化学关键。
DNA amplification（DNA 扩增）▾
一句话：PCR 把每一个邻近事件产生的少量 DNA 指数级放大到可检测水平。
作用：把单个蛋白识别事件放大成千上万个拷贝，是飞摩尔级灵敏度的来源；但也会引入 GC/长度偏好，需用 UMI 校正。
Sequencing readout（测序读出）▾
一句话：用下一代测序（NGS）读出每条 DNA 条形码的序列与拷贝数。
作用：把多重上限从 qPCR 荧光通道数解放出来——Wik 2021 起 Olink Explore 才从 qPCR 改为 NGS，实现 ~1500→5400+ 蛋白并行。
Protein barcode（蛋白条形码）▾
一句话：每一个靶蛋白对应一段独特 DNA 序列，序列身份 = 蛋白身份。
作用：测序仪不需要认识蛋白，只要读出"这段序列出现了多少次"，就能反推出该蛋白的相对丰度。
Multiplex protein quantification（多重蛋白定量）▾
一句话：在同一份微量样品里同时测几百到几千个蛋白。
作用：这是从 1-plex（2002）→ 96-plex（2014）→ ~1500-plex（2021）→ 5400+（Explore HT）的主线驱动力；NGS 读出是多重数量级跃升的关键。

10. 机制边界（A / B / C / D 分类）▾

A · 高度匹配（核心方向）

判据：溶液相 + 双抗体夹心 + oligo 邻近 + 模板依赖核酸反应 + NGS 读出，五项全满足。

  • Wik 2021 / Olink Explore（MCP，10.1016/j.mcpro.2021.100168）——本家族首个 PEA+NGS 闭环，~1500-plex。
  • Olink Reveal 2025（J Proteome Res，10.1021/acs.jproteome.5c00571）——第三方独立评测的 PEA+NGS 平台。
  • Prox-seq 2024（Nat Protoc，10.1038/s41596-024-01030-x）——把 proximity 从定量蛋白升级到定量蛋白复合体，单细胞 NGS。

B · 机制高度相关

判据：确实出现双抗体/双探针 proximity 或核酸连接/扩增，但某一步或 readout 与 A 不一致（多为 qPCR/RCA/CyTOF 读出，或非标准夹心）。

  • PLA/PEA 经典：Fredriksson 2002、Gullberg 2004、Söderberg in situ 2006、Lundberg PEA 2011、Assarsson 2014、Lundberg multiplex PLA 2011（readout 均为 qPCR/RCA 显微）。
  • 近作：MPX 2024（DNA 像素邻接）、PADSE-seq 2025（单锚扫描）、sc-aPL 2024（化学活性探针）、Phospho-seq 2025（胞内单抗体 barcode）。

C · 相邻技术（不依赖双抗体 proximity）

判据：用抗体/适配体 + 核酸标签，但不要求两个识别分子邻近同时结合；或单分子数字计数但无核酸读出。

  • 单抗体 barcode：CITE-seq / REAP-seq / AbSeq / TotalSeq（ADT 计数，无第二抗体、无邻近触发反应）。
  • PLAYR 2016（CyTOF 金属标签质谱流式，非 NGS；proximity 发生在 RNA 探针间）。
  • SomaScan（SOMAmer 适配体，荧光微阵列 Cy3 RFU，非抗体、非 NGS）。
  • Simoa（酶标 + 飞升级微孔单分子荧光计数，无核酸标签）。
  • MaMBA/BLISA 2025、PLAMseq 2025（TurboID 邻近标记 + MS/NGS）。

D · 仅作背景

判据：无核酸标签、无邻近机制的传统方法，仅用于能力对照。

  • ELISA、Western blot（光学/条带读出）。
  • LC-MS/MS（无抗体、无核酸标签，质谱鉴定）。
  • 大样本平台对照：Ferkingstad 2023 Nature（Olink vs SomaScan）、Olink 3072 vs 质谱 2025。
三条必须记住的边界： ① PEA(extension) ≠ PLA(ligation)，前者用聚合酶、后者用连接酶； ② SomaScan 用适配体(SOMAmer)不是抗体，读出是荧光微阵列不是 NGS； ③ Simoa 无核酸标签（酶标+单分子光学计数），传统质谱无抗体无核酸标签。

11. 新手知识地图与学习路线▾

9 步学习路线

1. ELISA / sandwich

先搞懂经典夹心法：捕获抗体 + 检测抗体 + 光学读出。这是所有"双识别"的起点。

2. Antibody–antigen recognition

理解表位、亲和力、交叉反应——为什么一对配对抗体能决定特异性。

3. Oligo-conjugated antibody

学抗体-寡核苷酸偶联：DAR、位点特异 vs 随机化学偶联、偶联对亲和力的影响。

4. Proximity assay

理解"为什么两个分子靠近才出信号"：邻近事件 = 双重识别的生物学逻辑。

5. PLA / PEA

对比 ligation（连接酶）vs extension（聚合酶延伸）两条分支，读 Fredriksson 2002 与 Lundberg 2011。

6. Nucleic-acid amplification

PCR/qPCR/RCA 扩增原理与偏好；UMI 如何校正 PCR 重复。

7. NGS basics

Illumina 短读长测序原理、建库、barcode/index、reads/UMI 计数。

8. Sequencing-based proteomics

读 Wik 2021（Olink Explore）与 Prox-seq 2024，理解 readout 从 qPCR 到 NGS 的跃升。

9. 区分 A/B/C/D

拿模块 10 的判据去看每篇新文献：是不是双抗体、有没有邻近、读出是不是 NGS。
